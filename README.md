## The username

> agysabda

Eight letters, one word — the entrant's own handle, sent exactly as it is: no explanation, no links, no pitch.

## How it works

`main.py` writes the username to `/output/entry.txt`, deterministically (repeated runs produce byte-identical output, verified by a read-back check).

```sh
python3 main.py
cat /output/entry.txt
```
